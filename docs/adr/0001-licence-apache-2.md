# 0001 — Licence Apache 2.0

Date : 2026-11-24. Statut : acceptée.

## Contexte

Rissio est open source et public. Il réutilisera des briques MIT, BSD-3 et Apache 2.0.

## Décision

Le code de Rissio est publié sous licence Apache 2.0 : permissive, avec une licence explicite sur les brevets.

## Alternatives écartées

- MIT : plus courte, mais sans licence explicite sur les brevets.
- GPL/AGPL v3 : empêche les forks fermés, mais freine la réutilisation de la librairie de stats.

## Conséquence

Ne pas intégrer de brique AGPL (dont Ultralytics YOLO) sans décision explicite et nouvelle ADR.
